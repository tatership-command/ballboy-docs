# v1.0.57 — Ball Boy Can Explain Itself Now

_Released 2026-08-13_

## Under The Hood

Nothing changes for you in this release. No command behaves differently, no message looks different. This is entirely about what Ball Boy records while it works.

**🔎 An advance can now be read start to finish**

When a season advance runs, Ball Boy now writes down each step as it happens — which season it resolved, whether it could post where it needed to, each game thread as it's created, who got added, whether the weekly announcement went out, and how long the whole thing took. Every one of those entries is stamped with the same ID, so the entire operation can be pulled up as a single story rather than pieced together from scattered fragments.

Previously it only wrote down failures, and not all of them. When something went wrong there was no record of how far it had gotten — the timeline had to be reconstructed by hand from Discord itself.

**⏱️ The specific thing that went wrong on August 9th is now visible**

That outage happened because one call to Discord never came back while Ball Boy was holding a lock that every other league was waiting on. From the outside it looked like the bot had simply stopped. There was no way to tell whether it was stuck waiting for that lock, stuck holding it, or stuck somewhere else entirely.

Ball Boy now records when it asks for that lock, when it gets it, and how long it waited. If the same thing happens again, the answer is in the logs instead of requiring a forensic dig.

**🔒 Nothing about you is recorded**

These records contain league and game identifiers and timings. No message content, no member details, no credentials — and there's now a check in place that prevents web addresses from being written into error text, since those can carry access keys.

## What's Next

This release covers the season-advance path. Commands and background work are still quiet by comparison, and that's the next piece.
