# v1.0.54 — Conference Championship Hero Images

_Released 2026-08-10_

## What's New

**🏆 Conference championship games get their own hero image**

Playoff games have had a hero image at the top of their thread for a while. Conference title games now get the same treatment — your conference's championship logo, both teams' logos side by side, and a gold **VS** between them.

All ten conferences that play a title game are included: ACC, American, Big Ten, Big 12, Conference USA, MAC, Mountain West, Pac-12, Sun Belt and SEC.

**📊 Conference record takes top billing**

Playoff heroes lead with a team's seed. A conference championship isn't decided by seeding, so these lead with the **conference record** in gold, with the overall record underneath.

## Fixes

**📛 "Week 18" is no longer the name of your championship game**

Conference title threads were being named `Week 18: Georgia vs South Carolina`. The week number was standing in for a name the bot never had.

They now read `SEC Championship: Georgia vs South Carolina` — and keep that name when the game is settled, instead of reverting to a week number. The results embed uses the same name, so the thread and the result agree.

Ball Boy works out which conference it is from the two teams playing, so nothing needs to be added to your schedule file for this to work.

**Worth knowing:** `/schedule` still shows "Week 18" for this week rather than "Conference Championships". That's a separate spot with a separate cause, and it's queued up next.
