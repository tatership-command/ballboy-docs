# v1.0.55 — Stream Role Fix, And Better Eyes On Discord

_Released 2026-08-11_

## Fixes

**🔴 `/admin roles` can set the stream role to everyone again**

Setting your stream notification role to **everyone** failed outright with *"Invalid role ID value for `stream`"*.

The command was doing the right thing — `everyone` is a documented, supported value for that slot, alongside a role or blank to clear. The problem was one layer deeper: the code that saves league settings checked that every role value looked like a Discord role ID, and `everyone` isn't a number, so it was rejected before it could be stored.

That check now knows about the `everyone` option for the stream role specifically. Every other role slot is unchanged and still requires a real role, and clearing a role still works exactly as before.

## Under The Hood

**🔍 Ball Boy can now see how long Discord is taking**

No change you'll notice — this is groundwork.

After the outage a few days ago, Ball Boy got a time limit on every call it makes to Discord, so one stuck call can't freeze it again. But there's a second kind of delay a time limit doesn't cover: when Discord asks Ball Boy to slow down, Ball Boy waits, and that wait sits outside the limit.

We didn't want to guess a number for that. So this release records how long Discord calls actually take, and how long Discord actually asks Ball Boy to wait — so the limit gets set from real measurements rather than a guess.

Nothing in these records identifies you or your league members, and no message content is stored.
