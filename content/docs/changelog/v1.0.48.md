# v1.0.48 — Screen-Share Detection & League Play Type

_Released 2026-07-29_

## What's New

**🖥️ Ball Boy spots your in-Discord screen share**
Share your screen in a voice channel and Ball Boy announces it in your game thread the moment you go live — no button, no command. The announcement calls out the **voice channel** so everyone can jump straight in, rather than linking a Twitch or YouTube stream.

It fires when you have an unplayed game for the current week, on a team you own, and your commissioner has set a streams channel (`/admin channels streams`). You get one announcement per game — restarting the share or hopping voice channels won't post again.

Worth knowing: this is a separate signal from Twitch detection. A screen share has no stream title, so the `/admin stream` match settings don't apply to it — those still govern Twitch announcements only. If you want to turn in-Discord detection off entirely, clear the streams channel.

**🎮 Set your league's play type with `/admin play_type`**
Leagues don't all play the same way, and Ball Boy now has a place to record which way yours does. A commissioner picks one of three:

- **User controlled** — members play out games with full stick control.
- **Coach mode** — members call plays and make pre-snap adjustments; the game AI handles the players after the snap.
- **Slow sim** — the game AI controls everything; members shape results through recruiting, depth charts, and coaching setup rather than in-game execution.

New leagues start as **user controlled**. Existing leagues stay unset until a commissioner picks one — nothing changes on its own. Check the current setting any time with `/league info`.

**To be straight with you: nothing behaves differently yet.** This release only records the setting. It's groundwork for features that genuinely need to know how your league plays — the clearest example being stream announcements, which should reasonably differ between a slow-sim league (where your opponent watches the sim) and a user-controlled one (where they shouldn't be watching at all). Setting it now means those features work correctly for your league the day they land.

## Fixes

**📺 Corrected the `/stream` profile option description**
The `profile` option said it "defaults to all your saved links." That stopped being true when stream announcements were unified — Ball Boy posts a single link: your saved default, or your first linked account if you haven't set one. The behavior was already right; only the help text was stale.
