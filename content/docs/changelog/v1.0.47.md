# v1.0.47 — Find Your Game Faster & Teams That Actually Free Up

_Released 2026-07-29_

## What's New

**📣 Ball Boy now announces when a team opens up**
Until now Ball Boy celebrated a team being *claimed* but said nothing when one became available again. It does now — whenever a team returns to CPU control, an announcement posts so everyone knows it's up for grabs. That covers all four ways it can happen: someone runs `/team leave`, a commissioner runs `/team release`, a member leaves the server, or `/draft start` clears listed owners' teams into the draft pool. Multiple teams freeing up at once are grouped into a single announcement rather than spamming the channel.

Release announcements go to your **team updates** channel (`/admin channels team_updates`). If a member leaves the server and you've set a **member updates** channel, that one is used instead. No channel set means no announcement — nothing else changes.

## Fixes

**🔎 The game picker is actually usable now**
Picking a game on `/season result` was close to unusable once a season got going. Three things were wrong at once: the dropdown listed Ball Boy's internal game key instead of the teams, so typing a team name filtered nothing; the list wasn't sorted before Discord's 25-item limit trimmed it, so the cap kept only the *earliest* weeks and the current week was unreachable; and it re-read your whole schedule on every keystroke.

The picker now reads `Week 4 — Georgia Tech vs W. Michigan`, with **your own game pinned to the top**, then the current week, then earlier weeks counting down. Games you've already reported stay in the list marked ✅ so you can still fix a wrong score. Typing a team name filters properly. The same fix applies to `/game schedule_time` and `/game delete_thread`, which share the picker.

**🧹 The roster board updates when a member leaves the server**
When someone left your Discord server their team was correctly handed back to CPU — but the pinned roster board kept showing them as the owner, sometimes for days, until an unrelated claim happened to refresh it. Anyone reading the board couldn't tell the team was actually free. The board now refreshes as soon as the member leaves.
