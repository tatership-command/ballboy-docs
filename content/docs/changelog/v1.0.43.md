# v1.0.43 — Cleaner Weekly Announcements & Clearer Week Prep

_Released 2026-07-24_

## What's New

**🏈 Cleaner weekly game announcements**
The weekly Games list is now leaner and easier to scan — team records and the "(CPU)" tag have moved off the announcement (you'll still find them in each game thread). Completed games now show the 🏆 right next to the winning score.

**📢 "Week Officially Started" note**
When a commissioner advances the season, every game thread for the new week now gets a clear **"Week N has officially started — good luck!"** message, so everyone knows play is live.

**🛠️ Clearer `/season prepare_week`**
Preparing an upcoming week no longer looks like an advance. The prep announcement now posts **silently** (no pings) and is labeled a **preparation** — "the season has not advanced yet" — and the confirmation reminds you to run `/season advance` when you're ready to officially start the week.
