# v1.0.58 — Ready to Advance Now Covers Every Action Week

_Released 2026-08-14_

## What's New

**✅ Ready to Advance shows up on more weeks**

The Ready to Advance button used to only appear on weeks with games. Offseason weeks — transfer portal, position changes, encouraging transfers, national signing day — have things for owners to actually do, but there was no way to say "I'm ready to move on." The commissioner was left asking in chat.

Ready to Advance now shows up on any week that needs action from team owners, whether or not there are games that week. Weeks that are pure commissioner review (season recap, training results) still don't show it — there's nothing for owners to confirm there.

Nothing changes for weeks that already had the button. If it showed up for you before, it still does, exactly the same way.
