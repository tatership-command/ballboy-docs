# v1.0.52 — Setup No Longer Says "All Set" When Role Sync Will Fail

_Released 2026-08-06_

## Fixes

**⚙️ `/admin roles setup` and `/admin roles sync_all` now agree**

If Ball Boy's role sat at the very bottom of your server's role list, `/admin roles setup` reported **"✅ All set!"** — and then `/admin roles sync_all`, the very next command it told you to run, refused to start.

Setup was only checking that Ball Boy had *a* role at all. Sync needs Ball Boy to sit above at least one slot, so it has somewhere to put the team and conference roles it creates. Setup now checks the same thing sync does, so the two can't disagree.

**📍 And it tells you how to fix it**

When the role position is the only thing wrong, the report no longer says "Some permissions are missing" and send you to the Integrations screen — nothing was missing, and that screen can't fix it.

Instead it names the real problem and the real fix: open **Server Settings → Roles** and drag **Ball Boy** above the team and conference roles it manages. It doesn't need to be at the top, just above the roles it creates.

Worth knowing: **Discord doesn't let a bot raise its own role**, so this is one an admin has to do by hand. Ball Boy can only tell you about it.

If a permission genuinely *is* missing, you'll get the same permissions guidance as before — that hasn't changed.

The `/admin roles sync_all` message you see when it stops now gives you the same instructions, so both commands point you at the same place.
