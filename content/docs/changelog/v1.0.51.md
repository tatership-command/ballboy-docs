# v1.0.51 — Advances Without a Configured Channel

_Released 2026-08-05_

## What's New

**📢 An advance no longer does nothing when a channel isn't set up**
If your league hadn't set an announcements channel, advancing the week posted no announcement at all — silently, with nothing to tell you why. Same for game threads if the game-thread channel wasn't set.

Ball Boy now falls back to your server's **system channel** (the one Discord uses for join messages) for those two, so an advance can't quietly produce nothing.

Two things worth knowing:

- **A fallback announcement never pings.** No `@everyone`, no announce role. You never designated that channel for league notifications, so blasting everyone in it would be presumptuous. Configure `/admin channels announcements` and pings work normally again.
- **If your server has no system channel either, nothing changes** — the advance stays quiet, exactly as before. The fallback never blocks an advance or turns a missing channel into an error.

This only affects leagues that haven't configured those two channels. If yours are set, nothing about your advances changes.

**🗓️ "welcome to week N" now triggers an auto-advance**
Announcement-style phrasing is a natural way to call the week, so `@YourRole welcome to week 6` now counts as an advance request, the same as saying "advance" or "next week".

It's deliberately narrow: it matches *"welcome to week"*, not a bare "welcome". A message like `@everyone welcome to the league` is still ignored, so greeting a new member won't advance your season.

*(This shipped in the previous update but wasn't listed in its notes.)*

## Fixes

**⚙️ `/admin channels` only offers channels Ball Boy can actually use**
The channel pickers accepted anything — including voice channels and categories — so it was possible to point a setting at a channel the bot could never post in. The mistake only surfaced later, when whatever needed that channel quietly failed.

Each option is now restricted to the channel types it genuinely supports. The game-thread option still accepts forum channels, so forum-based leagues are unaffected.

**Already pointed at a wrong channel type?** This doesn't fix existing settings — it only prevents new ones. Re-run `/admin channels` if you suspect something is misconfigured.

*(This also shipped in the previous update, unlisted.)*
