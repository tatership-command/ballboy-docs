# v1.0.68 — Champion Hero Finish

_Released 2026-08-27_

## Changes

**🏈 The CFP football now stands in for the zero in the year**

Just like the College Football Playoff's own championship mark. It replaces
only the zero in the century — so 2030 reads with one football and an
ordinary trailing zero.

**✨ Gold gradient on the year and on "CHAMPIONS"**

Both now use the same metallic gold sampled from the CFP mark itself, rather
than a flat colour.

**🌑 A shadow behind the champion's logo**

The background is tinted with the champion's own colours, so a dark logo could
sit almost flat against it. The shadow lifts it clear whichever team wins.
